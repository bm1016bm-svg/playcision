# 內測驗收與回報

不要只驗證桌面動畫。以下是交付條件，不代表全部已完成外網測試。

## 邀請前必須通過

- [ ] 雲端容器啟動成功，HTTPS 正常，4174 未對外公開。
- [ ] 邀請碼登入有效；錯誤碼、跨站 POST、未登入 API 均被拒絕。
- [ ] 桌面 Chrome／Safari；手機 Safari／Chrome 可完成探索→收藏→分享。
- [ ] 收藏後重新整理仍在；不同瀏覽器的收藏及排除互不影響。
- [ ] LINE／Discord 等複製內容含所選遊戲與可開啟 Steam 連結。
- [ ] 四位不同裝置／不同網路玩家可加入同房、準備、出牌、投票、看到一致結果；第五位被拒絕。
- [ ] 斷網重連、重啟伺服器後房間仍正確；過期房間提示重新開桌。
- [ ] 慢網路快速瀏覽推薦不白屏；長時間使用不持續增加卡片 DOM 與記憶體。
- [ ] 低階手機不因背景或推薦動畫而無法點選；減少動態效果偏好有效。
- [ ] 上游 Steam 暫時失敗時有重試提示，不清掉收藏、不顯示虛假成功。
- [ ] 測試邀請者已準備可用的回報聯絡管道，參與者知道傳給誰。

## 內測觀察

請玩家在沒有操作解說的情況下找一款想玩遊戲、分享給朋友，再一起選出一款。記錄在哪一步卡住、是否真的做出選擇、下次是否主動回來。不要用「滑了很多卡」代替「找到想玩的遊戲」。先以自願回報與觀察收集，不暗中加入追蹤。

回報範本：

```text
裝置／瀏覽器：
發生頁面：探索／推薦／收藏／分享／一起玩
操作步驟：
預期結果：
實際結果：
是否每次都發生：
截圖（遮住邀請碼、朋友名字及房間網址）：
```

資料遺失、看見別人的私人偏好、房間投票錯亂、登入可繞過：停止發新邀請並優先修復。畫面間距與文案問題可列入下一版，勿與阻塞問題混在一起。

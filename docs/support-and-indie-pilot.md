# 贊助收款與獨立遊戲試辦

## 已實作：綠界託管收款入口

署名旁提供「請我喝咖啡」及「免費支持」。三個方案使用下列原文：

| 金額 | 文案 |
| --- | --- |
| NT$ 100 | 幫作者把星巴克加到滿杯 |
| NT$ 500 | 可以繼續租伺服器，動起來了傑克 |
| NT$ 1,000 | 而你 我的朋友，你是椰汁城的傳奇 |

付款頁、收款紀錄、對帳及退款在綠界處理。本網站只提供公開連結，不接收信用卡資料、不保存付款者資料、不讀取綠界密鑰，也不把點擊或返回頁面當作付款成功。沒有收款連結的方案不可付款，不使用示範帳戶收錢。

### 作者要完成的設定

1. 從 [綠界官方快速收款頁](https://cashier.ecpay.com.tw/intro-quickpay) 進入註冊，依 [官方驗證說明](https://support.ecpay.com.tw/5095/) 完成身分、銀行及適用的服務審核。申請時如實填寫「Playcision 開發者自願支持／贊助」，是否承作以綠界審核為準。
2. 在綠界建立三個**固定金額、可重複使用**的收款連結，金額分別為 100、500、1000 元。確認沒有運費、額外收費、訂閱或不必要的寄送資料。實際可用付款方式依帳號開通狀態。
3. 確認付款頁顯示的收款人是你、商品描述與金額正確，再將三個公開網址填入專案根目錄的 `.env.local`：

```dotenv
VITE_ECPAY_100_URL=
VITE_ECPAY_500_URL=
VITE_ECPAY_1000_URL=
VITE_SUPPORT_REPOSITORY_URL=
```

4. 執行 `npm run support:preflight`。這個檢查只驗證官方網域、連結格式、重複連結及設定完整度；**無法證明帳戶所有權、實際金額、連結有效性或付款成功**。
5. 執行 `npm run check`，重建並重啟本地服務。Cloudflare 的前端建置也可使用同名公開環境變數，不需要另外部署收款伺服器。
6. 上線前由作者逐一開啟三個付款頁核對收款人與總金額，再以正式環境完成一筆自願的小額付款，回綠界訂單紀錄確認入帳。未完成這一步，不宣稱收款已驗證。

`VITE_*` 會出現在公開前端，**只能填公開收款網址，不能填 Merchant HashKey、HashIV、密碼或任何私密資料**。不確定的網址會停用；相同網址套到不同金額時全部停用，避免誤收金額。

採用官方已提供的託管連結是刻意選擇：這筆贊助不解鎖帳號權益，因此不需要自己維護付款訂單、回呼或額外金流資料庫。日後若加入付費權益，必須另做伺服器付款驗證，不能重用這個「點擊即離站」流程授權權益。

官方來源查閱日：2026-10-22。實際帳號、連結與正式付款尚待作者建立及驗證。

## 免費獨立遊戲曝光：待實作方案

首批以 3–5 款為試辦規模，台灣獨立開發者優先。以下是方案規格，**目前尚未開放申請、置頂或蒐集曝光數據**。

### 不做完整管理後台

先用私人申請表收件，由作者人工審核，再將通過的 Steam App ID 與起訖時間加入審核過的排程檔。公開專案只放通過的遊戲與公開排程，不放申請人的信箱、身分證明或退件內容。

若日後需要站內審核，做一個只限作者登入的審核頁（通過／退回／停播），權限必須由伺服器驗證。不能以隱藏網址、前端 localStorage 或開發者模式開關當作管理員驗證。

申請欄位：Steam 遊戲連結、團隊名稱、聯絡信箱、團隊所在地（自述）、官網／公開開發者身分證明、希望時段、同意公開彙總成效。台灣優先不需要收身分證或銀行資料。

審核流程：核對商店開發者與官網資訊；透過公開開發者聯絡管道確認申請權；確認有曝光素材使用權與公開成效同意；排除重複申請及排程衝突。未通過不自動發布。暫停與撤下需可隨時操作。

### 成效定義（實作時需遵守）

- 有效曝光：卡片至少 50% 可見並持續 1 秒；同一試辦、同一瀏覽器在 24 小時內只記一次。這是瀏覽器層級估算，不宣稱是唯一真人數。
- 收藏率：曝光後新增收藏的瀏覽器數 ÷ 有效曝光瀏覽器數；分母為零顯示「—」。只計從此試辦卡片產生的收藏，不能拿全站收藏數當分子；同瀏覽器重複收藏不重複累加。
- 外部跳轉點擊次數：點擊試辦卡片 Steam 連結的次數；排除作者測試、限制短時間重複點擊。只能證明離站意圖，不能證明抵達、購買或加入 Steam 願望單。
- 以伺服器時間決定 24 小時曝光期限。遵守玩家篩選條件；免費合作仍需標示「獨立遊戲試玩推薦／免費曝光合作」。
- 公開的僅是已同意的每日彙總報表與統計定義。不可在前端偽造人數、推算不存在的轉換或把內部測試當成真實曝光。

任何統計上線前需補隱私說明、短期去重與反灌水機制，不能在沒有告知的情況下加入全站追蹤。

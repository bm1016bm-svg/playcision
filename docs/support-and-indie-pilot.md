# 贊助收款與獨立遊戲試辦

## 當前收款進度（2026-10-29）

已在 PAYUNi 正式會員平台補上 Playcision 公開網址與營運說明，經作者確認後送出補件；商店狀態已從「待補資料」改為「審核中」。三個固定金額的一頁收款連結已建立，使用可重複收款、無指定期限的交易頁，僅勾選信用卡一次付清。

已逐一打開三個正式付款頁，核對 Playcision 名稱、官網、金額與下表文案；三頁均顯示「此收款連結審核中，尚未開放交易」，僅顯示信用卡支付選項，送出付款按鈕停用。**尚未核准收款，也沒有正式付款成功的紀錄。** 程式已替換舊版綠界設定，提供 PAYUNi 網址驗證及獨立的收款開放開關；審核期間保持關閉。

## 已完成的贊助介面

署名旁提供「請我喝咖啡」及「免費支持」，兩個入口各自開啟獨立內容。咖啡視窗只顯示贊助方案；GitHub 追蹤與點星星僅在免費支持視窗中顯示。兩者使用玻璃浮層，並支援減少動態、降低透明度與窄螢幕捲動。三個方案使用下列原文：

| 金額 | 文案 |
| --- | --- |
| NT$ 100 | 幫作者把星巴克加到滿杯 |
| NT$ 500 | 可以繼續租伺服器，動起來了傑克 |
| NT$ 1,000 | 而你 我的朋友，你是椰汁城的傳奇 |

目前沒有有效收款連結的方案不可付款。「免費支持」仍可使用，不會被當成付款或贊助紀錄。

## PAYUNi 一頁收款串接

入口僅連往 PAYUNi 官方託管頁，由 PAYUNi 處理付款、紀錄、對帳及退款。Playcision 不接收信用卡資料、不保存付款者資料、不讀取金流密鑰，也不把點擊或返回頁面當作付款成功。付款流程不呼叫 Playcision Worker，不增加付款訂單資料庫或常駐主機。

建置環境或根目錄 `.env.production.local` 設定三個固定金額、可重複使用的正式收款網址；此檔案不提交 Git：

```dotenv
VITE_PAYUNI_COLLECTION_ENABLED=false
VITE_PAYUNI_100_URL=
VITE_PAYUNI_500_URL=
VITE_PAYUNI_1000_URL=
VITE_SUPPORT_REPOSITORY_URL=
```

目前只接受 `https://api.payuni.com.tw/api/uop/receive_info/2/1/` 下、綁定本專案商店代號的 21 碼英數收款連結。這是 2026-10-29 從正式平台建立並實測的格式，不是對 PAYUNi 未來網址契約的保證。其他商店、測試環境、一般 API／登入頁、額外查詢參數與轉址均不接受。若官方格式更改，須重新驗證並更新測試，不可直接放寬整個網域。

`npm run support:preflight -- --prepared` 檢查連結格式、商店代號、重複連結及設定完整度，允許收款開關維持關閉。`npm run support:preflight` 另要求開關為字串 `true`，否則傳回非零狀態。兩者均只檢查本機設定，**無法證明 PAYUNi 核准、實際金額、付款方式或交易成功**。

核准後的開放順序：

1. 到正式 PAYUNi 平台確認商店與信用卡一次付清已核准，三個連結均可用；檢查沒有開放分期或其他付款方式。
2. 再次核對三頁的商店、金額、文案；由作者自行進行真實信用卡驗收，核對 PAYUNi 的交易結果。不要把測試卡、頁面導回或付款按鈕點擊當作成功。
3. 將 `VITE_PAYUNI_COLLECTION_ENABLED` 改為 `true`，執行 `npm run support:preflight`、`npm run check`，重新部署並檢查正式網站三個按鈕。這是人工開放開關，不會自動追蹤審核進度。

只填連結、不開啟開關時，玩家仍看不到付款入口。關閉收款同樣要改為 `false`、重新建置及部署；緊急時也可在 PAYUNi 停用連結。

`VITE_*` 會出現在公開前端，**只能填公開收款網址與非機密開關，不能填 MerKey、MerIV、密碼或任何私密資料**。不確定的網址會停用；相同網址套到不同金額時全部停用，避免誤收金額。舊 `VITE_ECPAY_*` 設定不再生效。

付款頁僅公開商店聯絡信箱，未公開住址／電話；不額外要求贊助者提供姓名、電話或通訊地址，PAYUNi 的電子信箱必填仍保留。沒有開啟續期收款、物流或交易回呼。頁面選用一般「交易」分類，不宣稱可抵稅公益捐款；是否依法須開立憑證、辦理登記或申報稅款，不能由付款頁的發票資訊開關推論，仍需按實際身分與收款性質確認。

採用官方已提供的託管連結是刻意選擇：這筆贊助不解鎖帳號權益，因此不需要自己維護付款訂單、回呼或額外金流資料庫。日後若加入付費權益，必須另做伺服器付款驗證，不能重用這個「點擊即離站」流程授權權益。

官方參考：[PAYUNi](https://www.payuni.com.tw/)、[會員平台操作手冊](https://www.payuni.com.tw/docs/Public/Uploads/2024-07-16/6695d0e635f12.pdf)（一頁收款章節說明單次／重複使用及不指定日期的期限設定）。手冊版本為 2024-07-01，實際頁面行為於 2026-10-29 核對；本文不以舊手冊推定目前費率或稅務規則。

## 免費獨立遊戲曝光：待實作方案

首批以 3–5 款為試辦規模，台灣獨立開發者優先。以下是方案規格，**目前尚未開放申請、置頂或蒐集曝光數據**。

### 不做完整管理後台

先用私人申請表收件，由作者人工審核，再將通過的 Steam App ID 與起訖時間加入審核過的排程檔。公開專案只放通過的遊戲與公開排程，不放申請人的信箱、身分證明或退件內容。

若日後需要站內審核，做一個只限作者登入的審核頁（通過／退回／停播），權限必須由伺服器驗證。不能以隱藏網址、前端 localStorage 或開發者模式開關當作管理員驗證。

申請欄位：Steam 遊戲連結、團隊名稱、聯絡信箱、團隊所在地（自述）、官網／公開開發者身分證明、希望時段、同意公開彙總成效。台灣優先不需要收身分證或銀行資料。

審核流程：核對商店開發者與官網資訊；透過公開開發者聯絡管道確認申請權；確認有曝光素材使用權與公開成效同意；排除重複申請及排程衝突。未通過不自動發布。暫停與撤下需可隨時操作。

### 成效定義（實作時需遵守）

- 有效曝光：卡片至少 50% 可見並持續 1 秒；同一試辦、同一瀏覽器在 24 小時內只記一次。這是瀏覽器層級估算，不宣稱是唯一真人數。
- 收藏率：曝光後新增收藏的瀏覽器數 ÷ 有效曝光瀏覽器數；分母為零顯示「—」。只計從此試辦卡片產生的收藏，不能拿全站收藏數當分子；同瀏覽器重複收藏不重複累加。
- 外部跳轉點擊次數：點擊試辦卡片 Steam 連結的次數；排除作者測試、限制短時間重複點擊。只能證明離站意圖，不能證明抵達、購買或加入 Steam 願望單。
- 以伺服器時間決定 24 小時曝光期限。遵守玩家篩選條件；免費合作仍需標示「獨立遊戲試玩推薦／免費曝光合作」。
- 公開的僅是已同意的每日彙總報表與統計定義。不可在前端偽造人數、推算不存在的轉換或把內部測試當成真實曝光。

任何統計上線前需補隱私說明、短期去重與反灌水機制，不能在沒有告知的情況下加入全站追蹤。

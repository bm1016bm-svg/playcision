結論：內測部署檔案與本機驗證已交付；**尚未取得可對外發邀請的雲端驗收結果**。下一輪以 `docs/beta-release.md` 部署，再逐項完成 `docs/beta-acceptance.md`。

## 首次使用教學
探索、推薦、收藏、分享各自首次進入時顯示兩句操作說明；關閉狀態保存在該瀏覽器，清除網站資料後會再次顯示。已確認桌面與 390px 手機浮窗排版、四頁獨立提示。npm run check 通過（25 個測試檔、134 個測試）。

教學視覺更新：改為全頁半透明蒙版與手繪曲線箭頭，依實際元素位置定位，每頁兩步，可略過。已檢查桌面及手機探索兩步畫面，保留逐頁完成記錄。

推薦聚焦調整：桌面卡片依可用視窗放大，水平及垂直間隔超過視窗加卡片尺寸，避免同時露出兩款；每款滾動距離由 1000px 改為 500px，保留有界渲染與圖片預載。

推薦連線：當前至下一款加入隨滾動延伸的低亮度描線、細微電路折角及慢速脈衝，只繪製當前路段，不增加圖片預載數量。

連線光澤更新：紫、淡粉與冰藍沿路段漸層，分層柔光與細亮核心，慢速高光移動。保持原本滾動與有界渲染。

推薦續載：接近尾端 12 款時按 50 筆分頁抓取熱門暢銷，前端依 App ID 去重並保留瀏覽器排除項目；失敗可重試，無更多資料顯示看完提示。伺服器只保留最多 12 頁、5 分鐘的暫存，最多兩個同時查詢，每次瀏覽有 5000 offset 上限，非全站遊戲資料庫。篩選標題右側問號可關閉篩選並重播目前頁面教學。

- 教學捲動回歸：推薦頁開啟篩選 → 問號重播教學 → 完成／略過後仍可捲動。浮窗共用捲動鎖，最後一個浮窗離場才還原頁面捲動，避免切換動畫交疊造成永久鎖定。

- 評論標題列使用透明背景，不再疊加局部背景模糊；上緣保留焦點外框空間，避免關閉按鈕外框遭裁切。

- 收藏頁：售價合計固定在底部導覽上方；整理收藏可逐項移除，清空需確認。Discord 匯出改為裸網址，不再以角括號停用預覽；縮圖由 Discord 與 Steam 決定。

- 一般探索篩選改為向 Steam 查詢類型、平台、價格、人數及來源，並分批載入。快取依完整條件區分；失敗可重試，快速改條件時取消舊回應。成人選項尚未改為專門分類查詢，不應宣稱已支援成人作品搜尋。

- 探索所有來源均使用分頁查詢；剩餘 18 款時自動接續下一批，失敗停止重試並提供手動重試。候選物件保留最近 150 款、復原保留最近 50 次。預載接下來 24 款、已解碼圖片 LRU 上限 64，背景圖片最多 4 工作，伺服器圖片資料雙佇列。底部探索操作列與導覽固定於視窗，不受空狀態高度影響。


### 類型清單整理
- 分類內固定將常用類型排前，預設顯示八項；「更多類型」展開其餘選項。
- 已選的細分類型保持可見，搜尋會顯示所有符合項目，支援中文名稱與原始英文關鍵字。
- 繁體中文介面改用中文類型名稱，篩選仍傳送原始 Steam 標籤；新出現且尚未翻譯的標籤保留原名。
- 動作角色扮演、戰鬥競速、卡牌對戰等跨類型標籤重新歸類。


### 房間邀請入口
- 直接開啟帶有 room 的邀請網址會顯示房間加入表單，分享教學不擋住入口。
- 新朋友輸入暱稱前不顯示「請重新加入房間」錯誤。
- 切換到探索再回分享，仍預設顯示社群分享清單。


### 牌桌與封面手牌
- 手牌以遊戲封面呈現，已出牌及達到每人兩張上限時停用出牌。
- 房間使用加寬桌面，卡片依寬度排成四、三或兩欄，桌面隨內容長高，不再內嵌捲動。
- 新牌從出牌者座位方向滑入，落桌時帶輕微回彈與淡光；減少動態效果設定停用動畫。


### 載入語錄
- 中文介面依序顯示小字中文、斜體英文及作者；長句完整換行，不使用省略號或行數裁切。
- 使用提供的 JSON 語錄於開場、探索補牌／篩選重查空窗、推薦下一批載入；作者依檔案保留，出處尚未逐條核實。
- 每隔 6.5 秒輪替，卸載後停止。完成或失敗時停止顯示載入語錄。
- 首批與探索查詢結果預載前八張封面，最多等待 1.2 秒即顯示資料，剩餘預載在背景繼續；不保證慢速網路下所有封面已就緒。


### 收藏分欄
- 「歷史收藏」位於「整理收藏」左側，可新增、命名、重新命名、刪除資料夾，移除資料夾內遊戲，並用資料夾名稱分享清單。
- 歷史收藏為收藏區子頁面（`#history`），可返回收藏、用瀏覽器返回／前進，或重新整理繼續瀏覽；無浮窗與頁面滾動鎖。
- 桌面可直接拖動或長按收藏遊戲，手機一般列表保留滑動、長按後啟動；畫面暗化，顯示已建立的玻璃資料夾接收區。移動使用每幀位置更新，進入接收區打開資料夾，放開後直接儲存並停在目前畫面。沒有資料夾時才進入命名子頁面；新增並保存後保持資料夾列表。整理收藏為普通刪除功能，不是拖曳目標。Esc、取消指標或失去焦點取消拖曳並恢復滾動。
- 滑鼠移入或鍵盤聚焦時，照片以較薄的封面分層浮出，使用已解碼的商店封面、無照片標題字條，動作平緩不回彈；「更多選項」為小尺寸實心三點，無方框，包含改名、分享、刪除資料夾。刪除先顯示確認，取消不修改資料。
- 手機可長按遊戲旁拖曳把手；點擊把手亦可直接選資料夾，支援鍵盤操作。一般列表仍可滑動。
- 歷史收藏以獨立瀏覽器儲存鍵保存，目前不跨裝置同步。讀取或儲存失敗會提示且不清除原資料。
- 玻璃資料夾沿用使用者提供的 React 元件，放於 `src/web/components/ui/glass-folder-cards.tsx`；元件自帶 CSS，不需另安裝 Tailwind 或 shadcn。
- 收藏左欄顯示免費遊玩，右欄顯示收費遊戲，依 Steam isFree 分類；未提供價格仍顯示原有價格未知提示，不視為免費。
- 手機保持左右兩欄，縮圖改放各卡片文字上方；整理、移除、抽選及底部售價合計保留。

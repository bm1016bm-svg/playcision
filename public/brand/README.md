# Playcision brand assets

Derived from the two logo images supplied by the project owner on 2026-09-20. No generated replacements or remote font/image dependencies.

- wordmark.png: English crop for the consumer header; dark matte removed from lettering.
- wordmark-bilingual.png: full bilingual crop for loading and README.
- icon-180/192/512.png: original app tile cropped and resized, retaining its existing material and shadows.
- favicon.png / favicon.ico: tighter central-symbol crop for small browser tabs.

The web manifest supplies shortcut artwork. It does not add offline support or alter the local server architecture.
